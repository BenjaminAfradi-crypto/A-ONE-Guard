NFC-Tags für Zeiterfassung

Ein Tag pro Objekt. Mitarbeiter halten das Handy an den Tag und werden automatisch ein- oder ausgestempelt.

Tag ist erstellt

Schreibe genau diesen Link als URL/Website auf den NFC-Tag.

So funktioniert es

  1. Objekt auswählen und Tag erstellen.
  2. Den erzeugten URL-Link auf einen NFC-Tag schreiben.
  3. Mitarbeiter meldet sich einmal in A ONE Guard an.
  4. Handy an den Tag halten → A ONE Guard öffnet sich → Ein-/Ausstempeln automatisch.

Auf iPhones wird der Tag über den normalen NFC-Leser von iOS geöffnet. Das funktioniert nur, wenn auf dem Tag ein URL-Link gespeichert ist. Web-NFC direkt im Browser ist auf iPhones nicht verfügbar.
